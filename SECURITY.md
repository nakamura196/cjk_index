# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/nakamura196/cjk_index/security/advisories/new),
not in a public issue.

You can expect a first reply within a week. Fixes are released as a new
version of the gem and noted in CHANGELOG.md.

## Supported versions

Only the latest release receives security fixes.
